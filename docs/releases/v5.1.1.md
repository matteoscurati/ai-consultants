# Release v5.1.1

**Date:** 2026-09-10
**Type:** Patch — DeepSeek V4.1 Flash defaults and transparent cost estimates
**Previous:** v5.1.0

## Highlights

- DeepSeek now uses the official `deepseek-flash` API alias in every tier.
- Existing unpinned Pro/Flash defaults migrate during `configure`; explicit choices remain intact.
- Cost estimates disclose peak pricing and excluded cache/off-peak discounts.

## Model and transport

DeepSeek documents `deepseek-flash` as DeepSeek-V4.1-Flash. The existing text-only
Chat Completions transport remains in use. `max_quality` continues to request
`reasoning_effort=max`, with a 16,384-token completion budget. Other tiers leave
effort to the provider unless explicitly configured. No DeepSeek CLI is added.

The provider-reported model field is preserved as received. An alias is not
rewritten into a supposedly attested version name. Legacy Flash aliases remain
accepted upstream but are served by V4.1 Flash; pinning the requested name cannot
prevent provider-side routing changes.

## Pricing

The estimator uses peak cache-miss rates: $0.30/M input and $1.20/M output.
Off-peak rates and cached-input discounts can lower actual charges. Reports
explicitly identify this as an estimate, not a provider invoice. Other legacy
catalog entries retain their historical rates.

Sources: [DeepSeek models and pricing](https://api-docs.deepseek.com/quick_start/pricing/)
and [thinking mode](https://api-docs.deepseek.com/guides/thinking_mode/), checked
2026-09-10.

## Verification

Implementation commit `96816b5` passed all 32 CI suites. One authorized API smoke
returned HTTP 200, a structured response and the correct fix for an expiry-boundary
bug. Requested and provider-reported model: `deepseek-flash`; effort: max;
measured tokens: 119 input / 602 output. One attempt, no retry or fallback.

This verifies the transport contract, not a statistical model-quality gain.
The frozen P1.6 roster, model/effort selections and preregistration are unchanged.

## Breaking Changes

No interface or response field is removed. The default requested model and cost
estimates change. Existing pins are preserved, subject to upstream alias routing.

## Upgrade Guide

```bash
npx ai-consultants configure --show-parameters
npx ai-consultants configure
```

`configure` upgrades exact unpinned `deepseek-v4-pro` and `deepseek-v4-flash`
settings to `deepseek-flash`. To retain an explicit requested ID, use
`--set DEEPSEEK_MODEL=<id>` or `# ai-consultants:pin`. Environment overrides and
unrelated custom model IDs are preserved. Existing private API credentials remain
in their current configuration; this update does not import or rewrite them.
