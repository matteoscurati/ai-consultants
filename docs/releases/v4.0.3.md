# Release v4.0.3

**Date:** 2026-08-29
**Type:** Patch — upgrade the GLM consultant to GLM-5.3-Flash
**Previous:** v4.0.2

## Highlights

- GLM uses `glm-5.3-flash` in maximum, premium, and standard tiers.
- `max_quality` continues to request GLM's `max` reasoning effort; the economy tier remains `glm-4-flash`.
- Existing managed GLM defaults migrate forward while explicit model pins survive.
- A real single-attempt Z.AI smoke confirmed the exact model and API transport.

## What's New

### GLM-5.3-Flash default

New installations and runs without a GLM model override now request `glm-5.3-flash`. The same exact identifier is selected by the maximum, premium, and standard model tiers. This release does not change the Z.AI OpenAI-compatible endpoint, response budget, panel composition, routing affinities, or GLM's Methodologist persona.

`max_quality` still sends `reasoning_effort=max` and a 16,384-token response budget. The economy preset remains on `glm-4-flash`.

### Managed migration and cost disclosure

When `ai-consultants configure` rewrites a configuration, the exact historical generated values `glm-5.2` and `glm-5.3` advance to `glm-5.3-flash`. Values marked `# ai-consultants:pin` remain untouched.

GLM-5.3-Flash is explicitly listed as unpriced on the Coding Plan transport. The catalog also keeps legacy `glm-5.3` pins unpriced, preventing the estimator from presenting a fabricated fallback dollar rate.

### Exact-transport verification

One authorized live smoke used the shipped `query_glm.sh` adapter, the Z.AI OpenAI-compatible endpoint, `glm-5.3-flash`, max effort, a single attempt, and no retry. It completed with HTTP 200 and exit 0 in about 12 seconds; the response reported the exact requested model and measured 37 input plus 308 output tokens.

The model returned near-structured text rather than the requested JSON. The adapter handled that response as designed: it retained the `PONG` content, labeled the answer as an unstructured-provider fallback, reduced confidence to 5, and disclosed the format caveat. This smoke therefore attests transport, authentication, model identity, max-effort acceptance, token accounting, and fallback behavior; it does not claim strict JSON adherence from every GLM-5.3-Flash response.

## Breaking Changes

None — this release is backwards-compatible. Explicit GLM model pins are preserved.

## Upgrade Guide

```bash
# npx (no install)
npx ai-consultants "question"

# git clone install
cd ~/.claude/skills/ai-consultants && git pull

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/matteoscurati/ai-consultants/main/scripts/install.sh | bash
```

New installations use GLM-5.3-Flash automatically. Existing installations with an unpinned managed GLM value should run:

```bash
ai-consultants configure --force
```

Alternatively, set `GLM_MODEL=glm-5.3-flash` explicitly. A value marked `# ai-consultants:pin` will not be migrated.
