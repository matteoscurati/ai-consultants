# Release v4.0.0

**Date:** 2026-08-24  
**Type:** Major — ten-consultant panel and executable agent-host contract  
**Previous:** v3.5.0

## Highlights

- Cursor is removed from the consultant panel. Cursor remains supported as a host through SkillPort.
- `max_quality` now selects all ten consultants and applies each supported transport's strongest configured reasoning effort and response budget.
- Gemini 3.7 Flash High is promoted only on the exact authenticated `agy` CLI transport; the Google API transport remains on Gemini 3.1 Pro by default.
- Claude Code, Codex, and Gemini can launch the skill with private query files, caller-root-bounded context, and complete self-exclusion from consultation, follow-up, and synthesis.
- Runtime synthesis, schemas, templates, help, and reports use the coverage union without fabricating consensus or debate fields.

## What's New

### A focused ten-consultant panel

The panel now contains Gemini, Codex, Mistral, Kimi, Claude, Qwen, GLM, Grok, DeepSeek, and MiniMax. Cursor's adapter, model tiers, configuration, diagnostics, persona, tests, and cost surface have been removed. Host compatibility is unchanged: projects using Cursor can still invoke ai-consultants through SkillPort, but Cursor cannot answer as one of its own consultants.

All presets and routing paths operate on the ten-consultant roster. `max_quality` enables the full roster and carries the strongest provider-specific effort controls available through each exact transport, including GLM and DeepSeek at `max` and Grok at its highest supported setting. Subscription or credit-billed models without a reliable dollar price remain explicitly unpriced rather than receiving an invented fallback rate.

### Transport-specific model promotion

Gemini 3.7 Flash High completed an authenticated inventory check and live structured response through the shipped `agy` adapter. It is therefore the automatic CLI target for maximum, premium, and standard tiers; Gemini 3.7 Flash Low serves CLI economy. The distinct Google API transport did not complete an equivalent smoke, so its automatic tiers remain on `gemini-3.1-pro-preview`.

Mistral continues to separate `MISTRAL_CLI_MODEL=mistral-medium-3.5` from the API-only `MISTRAL_MODEL`. Fable 5 and the new Mistral API IDs remain explicit opt-ins because their exact transports were not verified. No failed launch silently substitutes another model, credential, or paid transport.

### Agent hosts execute the skill safely

Claude Code, Codex, and Gemini host integrations now share an imperative execution contract:

- questions and follow-up instructions travel through mode-600 temporary files rather than shell interpolation;
- `INVOKING_AGENT` excludes the host from the initial consultation, targeted follow-ups, and synthesis;
- `--context-root` accepts only regular, non-symlink files inside the caller project and stages them privately under the system temporary directory;
- staged files retain their original project-relative identities and are removed after context construction;
- every host exposes only the current `consult` and `help` workflows.

A real Claude Code/Sonnet launch from an external temporary project returned Gemini 3.7 High and Codex 5.6 Sol, delivered the caller's tagged context to both consultants, created no Claude consultant artifact, and left no staging directory behind.

### Honest coverage synthesis

Live synthesis and the local fallback now report the deduplicated coverage union. Removed consensus, debate evolution, comparison, and winner fields no longer appear in runtime output, schemas, templates, help, or active host instructions. A synthesis provider is also subject to the invoking-agent exclusion rule.

## Breaking Changes

- Cursor is no longer a consultant. Configurations that explicitly enabled Cursor or set `CURSOR_CMD` lose that provider; `configure` removes the obsolete settings.
- The consultant roster changes from eleven to ten, so integrations that assumed eleven named response files must update.
- Stale Codex and Gemini `debate` and `roster-audit` command files are removed from installed host bundles.

The new model identity metadata remains additive. Existing explicit model pins marked `# ai-consultants:pin` are preserved.

## Upgrade Guide

```bash
# npx, after npm publishes 4.0.0
npx ai-consultants "question"

# active git-clone installation
cd ~/.claude/skills/ai-consultants && git pull
```

Run the configurator once to remove obsolete Cursor settings and migrate only the exact managed historical Gemini CLI, GLM, and Grok defaults:

```bash
ai-consultants configure
ai-consultants doctor --live
```

No credential, authentication state, or explicit model pin is modified automatically.
