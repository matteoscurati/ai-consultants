# Release v5.1.2

**Date:** 2026-09-28
**Type:** Patch — Gemini 3.8 Flash, Grok 4.7 and Claude Opus 5.5
**Previous:** v5.1.1

## Highlights

- Grok 4.7 becomes the default and premium/maximum target.
- Opus 5.5 becomes the Claude standard/medium target; Fable 5.1 stays the default.
- Gemini CLI moves to 3.8 Flash High/Low. API Pro 3.1 remains the default.
- Thinking-token accounting and quoted configuration migrations are corrected.

## Models and configuration

Explicit pins, environment overrides, `--set` choices and unrelated IDs survive
configuration rewrites. Gemini Medium is an explicit CLI option. Flash 3.8 is also
an API opt-in with low/medium/high thinking; unsupported explicit levels fail
before dispatch. Grok standard/economy and Claude economy are unchanged.

## Costs

Grok 4.7 uses standard API-equivalent estimates and doubles both rates above
200K input tokens. Opus 5.5 uses $4/M input and $20/M output when exact provider
cost is unavailable. Gemini 3.8 promotional estimates use $0.75/M input and
$3.75/M output through 2026-12-31; the catalog needs refresh for the announced
standard rates afterward. Estimates exclude applicable cache, service and
subscription adjustments and are not invoices.

## Verification

Implementation commit `1f068ff` passed all 34 CI suites, with Bash 3.2, ShellCheck,
documentation contracts and npm exclusions verified. Authorized CLI smokes passed
for Grok 4.7, Opus 5.5 and Gemini 3.8 High/Low. Opus content identity was
provider-reported; Grok and Gemini retained capability-probed provenance.

The initial Gemini attempts were rejected because the smoke harness supplied
an unsupported --effort flag. Named High/Low variants already select the level;
separately authorized corrected attempts omitted that flag and passed. No automatic
retry or API fallback occurred. No new API smoke or model-quality benchmark is
claimed. Frozen P1.6 inputs remain unchanged.

## Breaking Changes

No interface fields are removed. Default models and estimates change; explicit
pins remain intact. Google API token totals can increase because billed thinking
is now included in the reported output count.

## Upgrade Guide

```bash
npx ai-consultants configure --show-parameters
npx ai-consultants configure
```

Use `--set` or `# ai-consultants:pin` to retain a specific model. Keep existing
private credentials in place; no project credential import is required.

For Gemini 3.8 CLI variants, leave `GEMINI_REASONING_EFFORT` unset and choose
High/Medium/Low with `GEMINI_MODEL`. Native API thinking is configured separately.
