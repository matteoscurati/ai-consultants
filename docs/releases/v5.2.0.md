# Release v5.2.0

**Date:** 2026-10-19
**Type:** Minor — host-controlled waiting, audit fixes and new model defaults
**Previous:** v5.1.2

## Highlights

- No generation timeout by default: the invoking host or person decides when
  to stop waiting, with `.proceed`/`.abort`, `kill -USR1` or Ctrl-C.
- Host consultations describe the caller's project, and API consultants (GLM,
  DeepSeek, MiniMax) finally receive their persona and JSON contract.
- Gemini 4 Argon, GPT-6.1 Sol, Mistral Large 4 (API) and Qwen3.8-Max become
  defaults; GLM-5.3 serves `max_quality`.
- Claude Code, Codex and Antigravity (`agy`) were verified live as hosts.
- Failure reasons name the real cause, including a blocked network.

## Waiting and stopping

Consultant and synthesis timeouts now default to 0 (no limit): a call cut off
by a client timeout was usually still billed while its answer was lost.
`consult_all.sh` prints `Output: <dir>` and a `Still waiting after Ns for:
<names>` heartbeat every `WAIT_HEARTBEAT_SECONDS` (30). `touch <dir>/.proceed`
(or `kill -USR1 <pid>`, or a first Ctrl-C) continues with the answers received;
during synthesis it skips the synthesis. `touch <dir>/.abort` (or SIGTERM,
SIGHUP, a second Ctrl-C) ends the run with 130/143/129. Stopped consultants
end with their whole process tree and are reported as `stopped`.

`agy` can print its whole answer and then never exit; when its output is one
complete JSON object unchanged for `AGY_EXIT_GRACE_SECONDS` (60), the run ends
it and keeps the answer. A positive `<NAME>_TIMEOUT` restores a hard limit.

## Correctness

- The context's working directory and project tree come from `--context-root`
  (hosts run from the skill root), and the report names that directory.
- Consultant answers and `synthesis.json` are canonicalized by jq programs and
  validated against schema v3; truncated or malformed JSON still fails closed.
- The semantic cache key includes model, transport, effort and persona.
- Fenced or prose-wrapped synthesis JSON is accepted; the synthesis call is
  included in cost and budget checks.
- `followup.sh --session` restores the original question; whole-panel
  follow-ups are recorded on the original session.
- Questions and API keys travel through stdin and pipes, never argv.
- Non-boolean flags, quoted `.env` markers, `SYNTHESIS_STRATEGY`, persona
  overrides, `cost-capped`, escalation, the classifier, the installer and
  `doctor` were corrected.

## Hosts

The `SKILL.md` contract takes the skill root from the directory holding
`SKILL.md`, so Codex and Antigravity find it in `~/.agents/skills` or
`<project>/.agents/skills` (agy also reads `~/.gemini/config/skills`). Codex has
no custom slash commands and its default sandbox blocks the network: approve the
escalation yourself (its automatic reviewer refuses to send files to external
providers) or use `--sandbox danger-full-access`. The Gemini CLI is legacy:
Google no longer serves it to individual accounts.

## Verification

All 34 suites, ShellCheck, Bash 3.2 and 5 syntax, generated-doc drift and the
70-file npm manifest are green. Live on 2026-10-19 (cache off, no retry): the
`balanced` panel and a panel with every consultant returned structured answers;
every stop path ran against real consultants with no process left; Claude Code,
Codex and agy ran the skill as hosts. A terminal Ctrl-C bug and the agy exit
hang were found live and fixed with regression tests. No model-quality benchmark
is claimed; frozen P1.6 inputs are unchanged.

## Breaking Changes

- Runs no longer time out by default. Set a positive `<NAME>_TIMEOUT` (or rely
  on `.proceed`/`.abort`) if you need a hard limit.
- Default models change as above; `configure` migrates only unpinned generated
  values, and pins, environment overrides and `--set` choices are kept.
- `scripts/lib/schema.json` is v3.

## Upgrade Guide

```bash
npx ai-consultants configure --show-parameters
npx ai-consultants configure
```

Use `--set` or `# ai-consultants:pin` to keep a specific model or timeout.
Credentials stay in the private user configuration.
