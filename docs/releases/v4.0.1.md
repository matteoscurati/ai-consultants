# Release v4.0.1

**Date:** 2026-08-24

**Type:** Patch — truthful installer presentation

**Previous:** v4.0.0

## Highlights

- The installer no longer displays the obsolete label `AI Consultants v2.10` while installing a 4.x package.
- The banner is intentionally version-neutral, preventing the same drift in future releases.
- A hermetic regression test renders the banner and rejects hardcoded package versions.

## What's New

### A truthful installer banner

The curl and git-clone installation paths previously began with a hardcoded `AI Consultants v2.10 - Installation` banner. The installed package, public binary, and runtime were correctly at v4.0.0, but the stale presentation made a successful installation look inconsistent.

The banner now reads simply `AI Consultants - Installation`. This is more reliable than loading the package version dynamically: on a fresh curl-piped install there is no checkout to read yet, while on an update the checkout still contains the old version when the banner is printed.

### Regression coverage

The installer suite now checks the rendered header itself. It requires the version-neutral installer label and fails if a package-style SemVer is hardcoded into that banner again.

## Breaking Changes

None. Installation behavior, files, commands, configuration, credentials, model selection, and runtime output are unchanged.

## Upgrade Guide

```bash
# npx, after npm publishes 4.0.1
npx ai-consultants version

# active git-clone installation
cd ~/.claude/skills/ai-consultants && git pull
```

No configuration or authentication migration is required.
