# Release v3.2.0

**Date:** 2026-07-25
**Type:** Minor — Claude moves to Opus 5 with adaptive-thinking-safe transports and billing
**Previous:** v3.1.1

## Highlights

- **Claude now uses `claude-opus-5` as its premium default** across direct configuration, model tiers, documentation, and cost tracking.
- **Claude CLI costs now come directly from the provider**, including adaptive thinking and cache charges that are absent from the visible answer.
- **Anthropic API thinking blocks are handled correctly**, and responses truncated by the shared thinking/output budget are rejected instead of synthesized as complete.
- **Existing generated Opus 4.8 defaults migrate to Opus 5**, while explicit model pins are recorded and preserved.
- **Opus 4.8 remains supported** for historical responses and intentional overrides.

## What's New

### Opus 5 premium default

The Claude consultant, premium/max/best quality tier, standalone adapter fallback, examples, and cost catalog now use the canonical `claude-opus-5` model ID. Standard and economy tiers remain on Claude Sonnet 4.6 and Haiku 4.5.

Opus 5 retains the previous $5 per million input tokens and $25 per million output tokens. The legacy Opus 4.8 rates remain available so historical sessions and pinned installations continue to be priced correctly.

### Exact Claude CLI usage and cost

Claude CLI mode now requests its JSON result envelope. AI Consultants extracts:

- the visible answer from `.result`;
- measured input, cache, and output usage from `modelUsage`;
- the provider-reported `costUSD`.

The exact provider cost takes precedence over local token-rate reconstruction. This includes adaptive-thinking and cache charges even though those tokens do not appear in the visible answer.

### Adaptive-thinking-safe API mode

Anthropic responses may place a thinking block before one or more visible text blocks. The parser now collects every visible `type=text` block instead of assuming the first content block contains the answer.

The new `CLAUDE_API_MAX_TOKENS` setting defaults to 16,384 tokens. Anthropic counts adaptive thinking and visible output against this shared budget. If the provider returns `stop_reason=max_tokens`, the consultation fails as truncated rather than entering synthesis as a complete response.

### Managed configuration migration

Older `ai-consultants init` templates wrote the then-current Opus 4.8 default as an ordinary value. Running `ai-consultants configure` now recognizes that exact historical generated default, upgrades it to Opus 5, and records managed provenance.

Explicit model choices are written with an `# ai-consultants:pin` marker and survive subsequent configuration refreshes.

## Breaking Changes

None — this release is backwards-compatible. Opus 4.8 remains selectable and priced.

If `CLAUDE_MODEL=claude-opus-4-8` was an intentional unmarked override rather than the generated default, reassert it once after upgrading:

```bash
ai-consultants configure --set CLAUDE_MODEL=claude-opus-4-8
```

## Upgrade Guide

```bash
# If installed via git clone
cd ~/.claude/skills/ai-consultants && git pull

# If installed via curl | bash
curl -fsSL https://raw.githubusercontent.com/matteoscurati/ai-consultants/main/scripts/install.sh | bash

# If used through npx
npx ai-consultants@latest "your question"
```

Refresh persistent configuration so a historical generated Opus 4.8 value migrates:

```bash
ai-consultants configure
ai-consultants doctor
```

API users may override the shared thinking/output budget if needed:

```bash
ai-consultants configure --set CLAUDE_API_MAX_TOKENS=32768
```
