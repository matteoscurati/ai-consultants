# Release v5.5.0

**Date:** 2026-10-24
**Type:** Minor — current models only, and Meta (Muse) as the eleventh consultant
**Previous:** v5.4.0

## Highlights

- **Meta joins the panel** (opt-in): Muse Wonder for the default, premium and
  maximum tiers, Muse Spark 1.3 for standard and economy, through the Muse Code
  CLI or the Meta Model API.
- **Contributor mode stays off.** Muse Code subscriptions default to it; every
  consultation switches it off, so Meta does not train on your code.
- **Superseded models are retired.** Every tier uses current models only;
  `configure` migrates old ones, and the economy tier moves to Claude Haiku 5.5,
  GPT-6 Luna, Grok 4.7 and GLM-5.3-Flash.
- **Prices re-verified** against every provider's official page (2026-10-24).

## What's New

### Meta (Muse)

| Tier | Model | Price per 1M tokens (in / out) |
|---|---|---|
| default, premium, maximum (`max_quality`) | `muse-wonder-1.0` (preview) | $4.00 / $20.00 |
| standard, economy | `muse-spark-1.3` | $1.25 / $4.25 |

Both models always reason. `META_REASONING_EFFORT` defaults to `high`
(`minimal`..`max`); `max_quality` uses `max`; `none` is rejected before any
request. The persona is The Systems Thinker.

**CLI (default).** Install Muse Code and sign in once, with a subscription or
pay-as-you-go:

```bash
curl -fsSL https://dev.meta.ai/install.sh | sh
muse        # first run: trust prompt and sign-in
```

Consultations run `muse exec` advisory-only: a private empty workspace, no
shell, no workspace writes, no web tools, no sandbox network, no personal rules
or skills, no session log, and the prompt through a file. The required flags
are checked before any request.

**API.** Set `META_API_KEY` (a Model API key, `LLM_...`) and Meta uses
`https://api.meta.ai/v1/chat/completions` unless `META_USE_API=false`. A request
that runs past Meta's non-streaming time limit (HTTP 504 `gateway_timeout`) is
not retried; lower the effort or the context.

**Contributor mode.** In Contributor mode Meta may use prompts, code, files and
responses to train its models in exchange for lower prices or more usage. Muse
Code subscriptions turn it on by default. AI Consultants passes
`--contributor-mode off` on every CLI run and never selects a Contributor model;
pinning `muse-spark-1.3-contributor` ($0.10/$0.20) for the API works but logs a
warning on every run.

Meta is opt-in: `ENABLE_META=false` until `configure` finds the `muse` CLI or a
key. With it, `max_quality` has 11 consultants (10 when the invoking host is
one of them).

### Current models only

5.5.0 removes superseded models from the tiers, the rate catalog, the tests and
the documentation. `docs/cost_rates.json` maps 94 retired IDs to their family's
current model.

| Tier change | Before | Now |
|---|---|---|
| Claude economy | Haiku 4.5 | `claude-haiku-5-5` |
| Codex standard | GPT-5.6 Terra | `gpt-6.1-sol` |
| Codex economy | GPT-5.6 Luna | `gpt-6-luna` |
| Grok standard/economy | Grok 4.5 | `grok-4.7` |
| GLM economy | GLM-4-Flash | `glm-5.3-flash` |
| Gemini API standard/economy | `gemini-3.1-pro-preview` | `gemini-3.8-flash` |

- `configure` replaces a persisted retired model, pinned or not. It keeps the
  pin marker, records `migrated-from=<old>` and writes the usual backup.
- `configure --set` refuses a retired model and names the replacement.
- A retired or unknown model selected at run time still runs, with a warning,
  and the session report lists it as unpriced rather than guessing a rate.

### Costs

Every catalogued price was checked against the provider's official pricing page
on 2026-10-24. DeepSeek V4 Pro moves to $1.32/$3.96 per 1M (was $0.435/$0.87).
Meta has no long-context premium; cached input is excluded from the estimate,
and a CLI run on a subscription is estimated at the API list rate.

## Verification

All 36 suites and ShellCheck pass, locally and in CI. A new `test_meta.sh` covers
the tiers, the rate catalog, the CLI arguments (with a fake `muse`), the API
request and its 504 handling (with a fake `curl`), the effort guard and the
Contributor-mode warning. Authorized live smokes on 2026-10-24, one call each
with no retry: Meta through Muse Code 1.4.12 (Muse Wonder, structured answer,
12 s, requested-only identity), Claude Haiku 5.5 through the `claude` CLI and
GPT-6 Luna through the `codex` CLI (both structured). The Meta API transport and
the Gemini API tier change are tested offline only. No model-quality benchmark
is claimed.

## Breaking Changes

- Retired model IDs are migrated by `configure`, including pinned ones, and
  `configure --set` no longer accepts them.
- A retired or unknown model is no longer priced at a fallback rate: it shows
  as unpriced, so a dollar budget does not count it.
- The economy and standard tiers use different models (table above).
- `max_quality` advertises 11 consultants instead of 10.

## Upgrade Guide

```bash
# npx (no install)
npx ai-consultants configure

# git clone install
cd ~/.claude/skills/ai-consultants && git pull && ./scripts/configure.sh

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/reasance/ai-consultants/main/scripts/install.sh | bash
```

To add Meta, install Muse Code (above) or set `META_API_KEY`, then run
`configure` again. Credentials stay in the private user configuration.
