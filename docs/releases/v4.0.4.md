# Release v4.0.4

**Date:** 2026-08-31
**Type:** Patch — remove stale internal surfaces and consolidate test infrastructure
**Previous:** v4.0.3

## Highlights

- The shared Bash test framework now drives both standalone suites and the comprehensive core suite.
- The full regression gate covers 24 suites, including the previously excluded common-helper regressions.
- The npm tarball contains active user documentation without the repository's release-note archive or maintainer-only release tooling.
- Stale setup, routing, output-path, and contributor guidance now reflects the maintained v4 behavior.

## What's New

### One shared test framework

`test_suite.sh` now delegates assertion accounting, rendering, sections, skips, and detailed summaries to `scripts/lib/test_helpers.sh`. Compatibility adapters preserve the core suite's existing call sites while removing the duplicate assertion implementation.

The shared detailed summary fails when no assertions ran or when any assertion failed. Dedicated regressions cover both gates. The common-helper suite also retains behavioral coverage for feature-flag recognition, Kimi stream parsing, fenced JSON responses, bare JSON responses, and confidence preservation.

### Smaller, clearer package and repository surface

The release removes uncalled internal helpers, the stale README changelog copy, and the redundant `.npmignore`. `package.json#files` is the authoritative npm allowlist. The published package keeps active documentation while excluding tests, fixtures, the GitHub release-note archive, and maintainer release tooling.

Compared with v4.0.3's package manifest, the tarball goes from 107 to 61 entries. Packed size falls from 340,662 to 268,831 bytes, and unpacked size from 1,145,406 to 929,330 bytes.

### Honest compatibility and guidance

The documented routing mode/count/timeout helpers remain available for sourced-library users. Six pre-existing settings with no runtime reader remain accepted as explicitly deprecated no-ops throughout v4.x: `SESSION_CLEANUP_DAYS`, `ENABLE_PROGRESS_BARS`, `ENABLE_EARLY_TERMINATION`, `USE_COMPACT_PROMPTS`, `ENABLE_SELECTIVE_CONTEXT`, and `MAX_FILES_PER_CONSULTANT`.

Current documentation now directs users to `doctor` and `configure`, uses the XDG consultation output location, and describes the actual smart-routing output. The deprecated `preflight_check.sh` and `setup_wizard.sh` remain compatibility forwarders.

## Breaking Changes

None. No consultant roster, model catalog, transport, coverage-union behavior, or user configuration key is removed.

## Upgrade Guide

```bash
# npx
npx ai-consultants doctor

# git clone install
cd ~/.claude/skills/ai-consultants && git pull

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/matteoscurati/ai-consultants/main/scripts/install.sh | bash
```

No configuration changes are required. Deprecated no-op settings remain accepted during v4.x.
