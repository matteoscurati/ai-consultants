# Release v3.5.0

**Date:** 2026-08-23

**Type:** Breaking — transport-aware model catalog, honest model identity, and a 10-consultant panel

**Previous:** v3.4.0

## Highlights

- Normal premium runs remain cost-balanced; `max_quality` gains a separate maximum tier for exact-transport-smoked subscription targets.
- Gemini 3.7 Flash High becomes the verified `agy` default; Low serves the CLI economy tier, while the unverified API transport remains on 3.1 Pro.
- Mistral Vibe uses `mistral-medium-3.5` through a dedicated CLI setting, while API IDs remain separate and opt-in until verified.
- Cursor is removed as a consultant; Cursor remains supported only as a SkillPort host.
- Responses distinguish requested models from provider-reported or capability-probed effective identity.
- GLM 5.3 and Grok 4.6 become the promoted defaults; new prices, unpriced disclosures, migrations, and 22-suite regression coverage ship with them.

## What's New

### A maximum tier that fails closed

`max_quality` no longer means simply “the normal premium tier with more consultants.” It selects the strongest targets that completed a smoke through ai-consultants' own adapter and output contract:

| Consultant | Normal premium | `max_quality` maximum | Promotion evidence |
|---|---|---|---|
| Gemini CLI | `Gemini 3.7 Flash (High)` | `Gemini 3.7 Flash (High)` | Authenticated inventory + live structured adapter response |
| Kimi | `kimi-code/k3` | `kimi-code/k3-256k` | CLI inventory + live response |
| Qwen3 | `qwen3.7-max` | `qwen3.8-max` only on an already-configured Token Plan transport | Provider-reported API model |
| MiniMax | `MiniMax-M2.7` | `MiniMax-M3` | Explicit CLI model + live response |
| Claude | `claude-opus-5` | `claude-opus-5` | Fable 5 timed out, so it remains opt-in |

Qwen is never silently redirected from DashScope or CLI mode to a different paid endpoint. Without the exact Token Plan configuration, maximum keeps Qwen on `qwen3.7-max`.

### Transport-aware Gemini and Mistral configuration

Gemini and Mistral no longer pretend that one model string works on both transports:

- Gemini keeps separate `GEMINI_MODEL` and `GEMINI_API_MODEL` values. Gemini 3.7 Flash High completed the exact `agy` smoke and is promoted for CLI maximum, premium, and standard tiers; Low serves economy. API mode remains on `gemini-3.1-pro-preview`, with `gemini-3.7-flash` opt-in until an API smoke passes.
- Mistral API continues to use `MISTRAL_MODEL`; Vibe uses the new `MISTRAL_CLI_MODEL`, defaulting to `mistral-medium-3.5` through `VIBE_ACTIVE_MODEL`.
- The official Mistral API IDs `mistral-medium-3-5`, `mistral-large-2512`, and `mistral-small-2603` remain opt-in because no Mistral API key was available for exact transport verification.

### Bounded advisory CLIs

Mistral runs in a temporary workspace with a read-only mode and bounded capability probes:

- Mistral verifies prompt/output/agent/workdir/max-turn capabilities and the built-in plan agent before dispatch.
- Gemini checks the authenticated `agy` inventory for the requested model before dispatch and strips SSH markers that would hide the macOS credential store.
- A failed or timed-out probe stops before a model request. A timeout, empty reply, or other failure after launch never triggers a silent alternate model or transport.

### Requested versus effective model identity

Response metadata adds:

```json
{
  "requested_model": "glm-5.3",
  "model_identity_source": "provider-reported"
}
```

`model_identity_source` is one of:

- `provider-reported` — the API explicitly named the effective model;
- `capability-probed` — the requested CLI model was present in an authenticated inventory;
- `requested-only` — the transport accepted the request but exposed no stronger content-model evidence.

The top-level `model` remains the best effective identifier available. Provider billing participants such as Claude CLI `modelUsage` are not misrepresented as content identity.

### Prices, unpriced targets, and migrations

The catalog now includes current entries for Fable 5, Gemini 3.7 Flash, Mistral Medium 3.5/Large 3/Small 4, Grok 4.6, and MiniMax M3/M2.7/M2.5. GLM 5.3 on the coding-plan endpoint, Qwen3.8-Max Token Plan, and K3-256k remain explicitly unpriced: reports disclose their exclusion instead of inventing a dollar rate or calling them free.

`ai-consultants configure` migrates only these exact historical managed values:

- `GEMINI_MODEL=Gemini 3.1 Pro (High)` → `Gemini 3.7 Flash (High)`
- `GLM_MODEL=glm-5.2` → `glm-5.3`
- `GROK_MODEL=grok-4.5` → `grok-4.6`

Obsolete Cursor settings are removed.

Values carrying `# ai-consultants:pin` remain unchanged.

## Breaking Changes

The Cursor consultant is removed, reducing the panel from 11 to 10 consultants and removing its runtime/configuration surface. Cursor remains supported as a host through SkillPort. Model metadata remains additive, and managed migrations preserve explicit pins.

`max_quality` can select subscription/credit-billed targets that have no reliable per-token USD price. They are disclosed in the cost caveat, but a dollar budget cannot cap consumption the estimator cannot price.

## Upgrade Guide

```bash
# npx (no install)
npx ai-consultants "question"

# git clone install
cd ~/.claude/skills/ai-consultants && git pull

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/matteoscurati/ai-consultants/main/scripts/install.sh | bash
```

Run the configurator once to remove obsolete Cursor settings and migrate managed Gemini CLI, GLM, and Grok defaults:

```bash
ai-consultants configure
ai-consultants doctor --live
```

No credential or authentication state is modified automatically.
