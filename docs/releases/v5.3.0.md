# Release v5.3.0

**Date:** 2026-10-20
**Type:** Minor — MiniMax-M3.1-Flash in every MiniMax tier
**Previous:** v5.2.0

## Highlights

- MiniMax-M3.1-Flash (released 2026-10-19) becomes the MiniMax model in every
  tier, including `max_quality`, replacing M2.5, M2.7 and M3.
- It always reasons, so the default MiniMax budgets grow to 16,384 tokens, and
  to 32,768 for the `mmx` CLI in `max_quality`.
- API mode forwards `MINIMAX_REASONING_EFFORT` and rejects `none`/`minimal`
  before the request.
- `configure` migrates unpinned generated MiniMax values; pins and models you
  chose yourself are kept.

## What's New

### MiniMax-M3.1-Flash

| Tier | Before | Now |
|---|---|---|
| economy | MiniMax-M2.5 | MiniMax-M3.1-Flash |
| standard, premium (default) | MiniMax-M2.7 | MiniMax-M3.1-Flash |
| maximum (`max_quality`) | MiniMax-M3 | MiniMax-M3.1-Flash |

M3.1-Flash has a 1M-token context and always reasons: effort runs from `low`
to `max` (provider default `max`), and the API refuses `none` with HTTP 400.
Its reasoning shares the completion budget, so the defaults grow:

| Setting | Before | Now |
|---|---|---|
| `MINIMAX_MAX_TOKENS` (`mmx` CLI) | 4096 | 16384 |
| `MINIMAX_API_MAX_TOKENS` | 4096 | 16384 |
| `MINIMAX_MAX_QUALITY_TOKENS` (`mmx` CLI in `max_quality`) | 16384 | 32768 |

API calls in `max_quality` keep the shared `MAX_QUALITY_API_MAX_TOKENS`
(16,384).

### Effort

In API mode, `MINIMAX_REASONING_EFFORT` is sent as the OpenAI-compatible
`reasoning_effort` (`low`, `medium`, `high`, `xhigh` or `max`); `none` and
`minimal` fail before any request is sent. The `mmx` CLI, the default
transport, has a `--model` flag but no effort flag, so CLI runs use the
provider default.

### Costs

Estimates use the list price: $0.15 per 1M input tokens and $0.60 per 1M output
tokens (`minimax-m3.1-flash` in `docs/cost_rates.json`, also the `minimax`
fallback). Older MiniMax rates stay in the catalog for pinned models and past
responses. `mmx` reports no usage, so CLI token counts are estimated, and
estimates are not invoices.

## Breaking Changes

- The default MiniMax model changes in every tier, and the default MiniMax
  budgets grow; a larger budget can raise the cost of a long answer.
- With `MINIMAX_USE_API=true`, `MINIMAX_REASONING_EFFORT=none` or `minimal`
  for M3.1-Flash now fails before the request instead of reaching the API.

## Upgrade Guide

```bash
npx ai-consultants configure --show-parameters
npx ai-consultants configure
```

`configure` moves unpinned `MiniMax-M2.5`/`MiniMax-M2.7` and the generated
4096/4096/16384 budgets to the new defaults. A pinned value
(`# ai-consultants:pin`), an environment override or a model you set yourself,
such as `MiniMax-M3`, is kept: set `MINIMAX_MODEL=MiniMax-M3.1-Flash` and the
budgets above to move it. Credentials stay in the private user configuration.
